\subsection{Experimental setup}

We evaluate PSB on three image classification streams: \emph{[MNIST
protocol]} based on MNIST~\cite{lecun1998gradient}, \emph{[CIFAR
protocol]} based on CIFAR~\cite{krizhevsky2009learning}, and the
\emph{[CORe50 scenario]} of CORe50~\cite{lomonaco2017core50}. These
streams contain \textit{TBD}, \textit{TBD}, and \textit{TBD} tasks,
respectively. We use the \emph{[class, domain, or task incremental]}
evaluation protocol for each stream. Task identity is
\emph{[available or unavailable]} at test time. No method retains
examples from completed tasks.

All methods use the same classifier architecture, data preprocessing,
task order, and training budget within each benchmark. We compare PSB
with fine-tuning, online EWC~\cite{schwarz2018progress}, synaptic
intelligence~\cite{zenke2017si}, VCL~\cite{nguyen2018vcl}, and an
ensemble baseline with the same number of networks as PSB. Each method
is run with $20$ paired seeds. Paired runs share the task order and,
where applicable, the initial network parameters. Hyperparameters are
selected using \emph{[validation protocol]}, with the same tuning
budget for every method. PSB uses $K=\mathrm{TBD}$ networks,
\textit{TBD} temperature levels, and \textit{TBD} IMF rounds per
boundary. The Langevin move budget, bridge noise $\sigma$, Fisher decay
$\gamma$, and classifier architectures are \emph{[values]}.

Let $a_{t,j}$ be test accuracy on task $j$ after learning task $t$.
We report final average accuracy
$A_T=T^{-1}\sum_{j=1}^{T}a_{T,j}$ and average forgetting
$F_T=(T-1)^{-1}\sum_{j=1}^{T-1}
(\max_{j\leq s<T}a_{s,j}-a_{T,j})$.
Results are reported as the mean and standard deviation across paired
seeds. We also report the paired difference between PSB and the
strongest baseline for each benchmark.
